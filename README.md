# 抽象棋線上原型

這是依照《抽象棋桌遊》規則文件製作的即時多人網頁原型。使用 Node.js 與 WebSocket；玩家可建立房間，分享四碼代碼，供 2–4 名異地玩家加入。

## 本機啟動

1. 安裝 Node.js 20 或更新版本。
2. 在本資料夾執行 `npm install`。
3. 執行 `npm start`，並開啟 `http://localhost:3000`。

## 異地遊玩

把整個專案部署到支援 Node.js 長連線/WebSocket 的服務（例如 Render、Railway 或 Fly.io），服務啟動命令設為 `npm start`。部署完成後，所有玩家開啟同一個 HTTPS 網址，由其中一人建立房間，其他人輸入房間代碼加入。若使用免費休眠方案，首位玩家可能需要等服務喚醒。

房間狀態目前保存在伺服器記憶體中；伺服器重啟後房間會關閉。網址必須使用 HTTPS/WSS 才適合公開遊玩。不要把本機 `localhost` 網址分享給遠端玩家。

## 原型採用的暫定規則

- 棋盤採 3×3 方格及上下左右移動。
- 每位玩家起手 3 枚棋子，並保證至少有 1 枚等級一棋子；起始玩家隨機選出。
- 回合開始時會在棋局紀錄及棋盤角落標示目前玩家。
- 輪到自己創造動物時，手牌會依照棋盤堆疊規則高亮可放置的棋子。
- 移動時只需移至上下左右相鄰格，不受創造動物的等級限制；每格只顯示最上方棋子，旁邊標示該格棋子總數，滑鼠停留時可查看效果資訊。
- 三條食物鏈各13枚：等級一7枚、等級二4枚、等級三2枚；另放3枚變色龍棋。
- 變色龍不需指定等級，放置時依可用位置視為任意等級；二、三級動物可創造在變色龍上，一級動物不可。變色龍沒有移動或揭露效果。
- 同一食物鏈的一、二、三級棋子各一枚連成直線，或三枚變色龍連成直線時，連線上的棋子回到抽袋。
- 地鼠移動效果與兔子揭露後的自選相鄰移動已實作；兔子移動引發的其他揭露效果會依序進入效果佇列，目前只有兔子效果會自動結算，其餘揭露效果尚待實作。
- 每回合需要創造及移動各一次。創造動物依空格與逐級堆疊規則判定；原文另述的手牌達 8 枚淘汰、無法行動抽牌及特殊效果，仍需按完整規則確認後逐步補齊。

## 待確認的規則

1. 是否允許斜向移動。
2. 各動物特殊效果的合法目標與連鎖順序。
3. 回合抽牌時機、抽袋耗盡後的處理、手牌達8枚的淘汰時機。
